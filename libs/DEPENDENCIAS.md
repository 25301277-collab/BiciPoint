# Dependencias incluidas

Las bibliotecas se sirven desde el mismo sitio para que el menú, los iconos y la validación no dependan de un CDN.

| Biblioteca | Versión | Licencia |
| --- | --- | --- |
| Bootstrap | 5.3.6 | MIT, LICENSE-bootstrap.txt |
| Bootstrap Icons | 1.13.1 | MIT, LICENSE-bootstrap-icons.txt |
| SweetAlert2 | 11.26.25 | MIT, LICENSE-sweetalert2.txt |

Fuentes de distribución de los archivos añadidos: paquetes oficiales `bootstrap-icons@1.13.1` y `sweetalert2@11.26.25` en jsDelivr. Bootstrap ya estaba incluido en el proyecto recibido.

DM Sans y Outfit se solicitan a Google Fonts mediante HTTPS; la interfaz conserva Arial como alternativa. Las cuatro fotografías y los SVG se conservaron de los archivos originales del proyecto; la copia recibida no incluye créditos adicionales para esas fotografías.
